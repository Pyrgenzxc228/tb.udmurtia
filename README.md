# TB Registry

Автоматизация чек-листа диспансерного учёта по туберкулёзу (Удмуртская Республика).

Автономная система для развёртывания на сервере учреждения.
Backend: Java 17+ / Spring Boot 3 / PostgreSQL 16. Frontend: Thymeleaf.

## Требования

- JDK 17+ (у вас Java 25 — подходит)
- Docker + Docker Compose
- Maven не нужен: используется Maven Wrapper (`mvnw`)

## Статус

В разработке.
